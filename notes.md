# My Claude Code Notes

## Section 1: In-built Commands
***/usage***: to check how usage of tokens, 5 hours limit, the weekly limits

***/context***: to check the number of tokens used in this conversation.

***/model***: to pick any LLM coding model. Do not change model halfway, previous model will lost memory.

***/compact***: to compress the context, keep the most relevant details, and discard the rest.

***/status***: check Claude version, session and current model.

***/doctor***: resolve Claude dependencies, update to latest.
